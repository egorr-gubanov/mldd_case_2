# BPMN AS-IS: бизнес-процесс до внедрения системы

Модель в нотации **BPMN 2.0** (дорожки участников, задачи User/Manual/Service, исключающие шлюзы XOR).

Текущий процесс: после сканирования пропуска дежурный **вручную** сравнивает лицо сотрудника с фотографией в профиле СКУД. Решение о допуске принимает человек.
