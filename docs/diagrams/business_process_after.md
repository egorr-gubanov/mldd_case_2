# BPMN TO-BE: бизнес-процесс после внедрения системы

Модель в нотации **BPMN 2.0**. Целевой процесс с ML-системой идентификации, СКУД и участием дежурного только в спорных случаях.

## Что меняет разрабатываемая информационная система

| Было (AS-IS) | Стало (TO-BE) |
| --- | --- |
| Дежурный визуально сравнивает лицо с фото | ML-система автоматически идентифицирует сотрудника по кадру |
| Решение субъективное | Решение по порогам уверенности ML |
| Дежурный в каждом проходе | Дежурный только при спорном результате или сбое |
| Нет журнала уверенности | Audit log: score, причина, версия модели |
| Риск прохода по чужому пропуску | Liveness + сопоставление с биометрической базой |
